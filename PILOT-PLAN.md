# Agora Scout — Pilot / Traction Plan (Lepton + Circle grant M1)

> The product is now self-serve: **/manage** lets anyone create a managed account, fund testnet USDC, watch the agent rebalance, and withdraw. The build is no longer the bottleneck. **Users are.** This plan is how we get them and make the growth undeniable to judges.

## The one metric that wins
Lepton judges **only post-June-15 progress** and explicitly **penalize projects with no users**. So the scoreboard is simple:

> **treasuries managed** (live on the dashboard footer) going from 0 → a real, climbing number.

Everything below serves that single number.

## Three tiers of users (easiest → highest-value)

### Tier 1 — Fellow hackers (get 10-30, this week)
The warmest, most crypto-native audience that will actually click a testnet link.
- Post in the **Lepton Discord** as a returning builder: 1 line + 20s Loom + the /manage link.
- Ask directly: "Spend 60 seconds — create an account, grab faucet USDC, watch the agent manage it, withdraw. Tell me what breaks."
- Reciprocate: try their projects, comment. Builders test builders.

### Tier 2 — Arc / Circle / CT community (get 50-200 visits, 10-30 accounts)
- One **Crypto-Twitter thread** from @mega2608: the verifiable angle wins here.
  Hook: *"I built an AI that manages a USDC treasury on Arc — and every move it makes is committed on-chain BEFORE the money moves. You can verify it yourself, and try it with your own testnet USDC. 🧵"*
  Beats: the problem (idle USDC / emotional management) → the agent → commit-then-act proof (screenshot Arcscan) → **try it (/manage link)** → what's next (mainnet + real yield).
- Repost in Arc/Circle dev channels. Tag the verifiable primitive — it's the differentiator.

### Tier 3 — Real treasuries (get 1-3 quotes/LOIs — grant gold)
Hardest, highest-value for the **grant** (it asks for "pilots, partnerships, a credible path").
- Target: small DAOs, on-chain funds, crypto-native businesses sitting on idle USDC.
- Ask is tiny: a 15-min call + "would you point idle treasury USDC at an autonomous, fully-auditable agent on mainnet when it's ready?" A written *yes* / intent-to-pilot is enough.
- Even 1-2 named quotes transform the grant application from "demo" to "validated."

## The pitch (copy-paste)
**One-liner:** "Park idle USDC. An autonomous agent manages it across market regimes — every move committed on-chain before it happens, verifiable by anyone. Try it free on testnet in 60 seconds."

**Why it's different:** not "trust the bot" — *prove* the bot. Commit-then-act + a public verifier is a trust primitive nobody else in the cohort shipped.

## Lepton theme fit (nanomoney)
Lepton = nanomoney / per-action value on Arc. Frame the **management fee as nanomoney settlement**: the agent takes a few bps **per rebalance**, settled per-action in USDC on Arc — money too small to move before, moving now. (Optional small build: a per-rebalance fee transfer to a fee wallet, surfaced as "fees settled.")

## Make growth visible to judges
- Dashboard footer now shows **"N treasuries managed."** Keep it climbing.
- (Next build, if time) add **"USDC under management"** (sum of account balances) + a small accounts-over-time sparkline. Judges should *see* the curve.

## Build-in-public (compounds everything)
Run the journey as content from @mega2608: "Didn't win Agora — here's the real lesson (traction, not code), and watch me get real users in Lepton." Honest arc + live product + climbing number = exactly what Canteen says they reward. Each user milestone = a post.
